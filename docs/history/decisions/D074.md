# D074. malが用意した範囲へhostが書く経路を持たない

- Status: Accepted
- Date: 2026-09-25
- Scope: C host ABI

## 決定

hostがwritableに受け取る範囲は、hostが所有するstorageだけとする。[D053](D053.md)にあった「hostがmalから借りたwritableな範囲を
初期化する」経路は、Region、Packedをmanaged Bufferへ置き換えた時点でsource-levelに存在しなくなったため、仕様から外す。
hostからmalへbytesを入れる手順は、hostが所有するstorageへ書かせ、`from<T>`でBufferへcopyする形だけである。

## 理由

BufferはpublicなC ABIへ出ず、Bufferから`Address`を得る操作もない。Addressはhostがauthorityを持つcapabilityであり、
mal-owned storageをAddressとして貸すと、この分担が崩れる。copyはI/Oと同じ量のbyte移動であり、通常は支配的でない。

## 採らない案

- Bufferをcall-scopedなwritable rangeとして貸す: 保持、初期化済み範囲、Bufferの破棄と再利用との衝突を新たに定める必要がある。
  copyが問題になった場合は、Addressを経由せずextern境界のadapterでnumeric scalar elementのBufferだけを貸す形から検討する。
