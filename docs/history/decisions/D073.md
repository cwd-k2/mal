# D073. process argumentを`(Address, USize)`のBufferで渡す

- Status: Superseded by [D076](D076.md)
- Date: 2026-09-25
- Scope: language (entry point), C host ABI, and reference compiler

## 問題

`main :: (USize, Address) -> Int32`は`argv[1]`以降のpointer列だけを渡すため、各argumentのbyte lengthを得るには`strlen`相当のhost
externが必要だった。C stringはmalでは「先頭Addressとbyte length」の組であり、entryがlengthを渡さない分だけprogramごとに同じ
externを宣言し、host側にも実装が要った。

## 決定

argument-aware entryの型を`Buffer<(Address, USize)>`にする。BufferはC shimが起動時に`argv + 1`の各C stringから作り、
要素は先頭Addressと終端NULを除くbyte lengthである。argument数は`#`で得られるので、従来の第一要素のcountは廃止する。

## 理由

lengthの計算はprocess argumentという入口の責務であり、entryで一度だけ行えば全programのextern宣言とhost実装が不要になる。
Bufferはmal-owned storageなので、`from<Address>`によるpointer列のcopyも要らず、要素はそのまま`get`で読める。
