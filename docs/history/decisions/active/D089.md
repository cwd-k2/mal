# D089. 型parameterは型名をshadowしない

- Status: Accepted
- Date: 2026-09-29
- Scope: generic declaration、name resolution

## 問題

generic alias、opaque type、generic binding、operation familyの型parameterは、predefined型やfile内の型と同じ名前を持てて、
declaration内でその型を黙ってshadowした。`narrow<Int32> :: (Int32, Int64) -> Int32`の`Int32`は型parameterになり、診断は
`expected Int32, found Int32`のように読めなかった。operation familyをrequireし忘れた`equal<Symbol> :: ...`は、implementationでは
なく`Symbol`という型parameterを持つgeneric bindingとして受理された。仕様はこのshadowingを定めていなかった。

## 決定

型parameterの名前は、そのdeclarationから見える型名（predefined型、直接requireしたfileから導入した型、同じfileのtop-level型）と
同じであってはならない。規則は[parametric polymorphism](../../../spec/generics.md#declarationとapplication)に置く。

## 理由

- [D077](D077.md)がpredefined名のtop-level再宣言を禁じたのと同じく、型項の読みをdeclarationの外の文脈へ依存させない。
- 型parameterはdeclarationごとに閉じた短い名前であり、衝突を避ける改名のcostは小さい。
- implementation keyの型名を型parameterと取り違える誤りを、名前解決で直接報告できる。
