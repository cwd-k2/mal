# D078. hostは宣言された全external operationを定義する

- Status: Accepted
- Date: 2026-09-25
- Scope: C host ABI and reference compiler

## 問題

external operationを値として参照するだけでapplicationしないprogramは、hostがそのoperationを定義しなくても`production`では
linkできた。LTOが使われないbridgeを除去するためである。`baseline`ではshimのbridgeが定義を参照し、同じprogramのlinkが失敗した。
仕様は定義のないoperationを扱っておらず、conformance caseは`production`だけで実行してこの差を隠していた。

## 決定

programが宣言したexternal operationは、applicationするかどうかにかかわらずすべてhost implementationが定義する。定義のない
operationを含むprogramのlinkは保証しない。規則は[C host ABI](../../../spec/c-host-abi.md#host-operation)に置く。

## 理由

- externの宣言はhostとのcontractの一部であり、programのどこで使われるかでcontractの範囲を変えない。
- `emit host`は既に全operationのstubを生成し、未実装のoperationをtrapするbodyで定義する手段を与えている。
- applicationされ得るoperationだけを要求するには、closure flowが証明した未使用functionのbridgeを全modeで省く必要があり、
  optimization有無でadmissionが変わらないというbaselineの原則を、flow解析の完全性へ依存させることになる。
