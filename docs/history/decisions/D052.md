# D052: genericsとcanonical external memory modelを採択する

Status: Accepted (2026-09-17); memory surface superseded by the current Buffer model (2026-09-23)

## 決定

v0.6は明示的parametric polymorphismを持ち、generic aliasとtop-level value bindingをwhole-program specializationで単相化する。
operationは通常のfunctionまたはproductとして明示的に渡し、user-defined constraint、dictionary、method lookup、type reflectionは
導入しない。memory indexed typeの形成に必要なclosed judgmentだけをsignatureから`Requirements(T)`として導く。

external memoryは`Address`、`ByteSize`、`USize`、compile-time layout shape、`Cursor<A>`、`Region<A>`で表す。representableな
primitive、product、sumにはtarget-localなcanonical memory layoutを再帰的に与える。exact placementとunaligned accessをbaseline、
align-upをtarget capabilityとする。loadは`(A, Cursor<A>)`、storeは次のCursorを返す。

external Regionとmal-owned immutable sequence `Packed<A>`の間でbulk transferする。`Symbol`は独立したmanaged byte valueとして保ち、
`Packed<UInt8>`とclosed prefix conversionで往復する。allocation、deallocation、permission、lifetime、partial I/O policyはextern
contractが所有する。

memory operationはbounds、permission、initialization、lifetime、valid representationを検査しない。callerまたはhost contractが
preconditionを満たし、違反時の結果は保証しない。防御的trapはsource contractではなくimplementation detailである。
一方、preconditionを満たしたoperationに必要なmal-owned allocationのfailureはtrapする。

surface syntaxはlowercaseのclosed layout shape、postfix numeric conversion、`@` placement、prefix/binary `<-`などへ統一する。
`T(value)`、`value[T]`、`T.size`、`T.load`、`T.store`、`Symbol.read`、`Symbol.write`を廃止し、型identifierをexpression operatorとして
使わない。`Ptr`はsource、compiler内部、process ABI、public C ABIから除き、`Address`へ置き換える。C ABIは`0x000700`とする。

## 理由

scalarごとのmemory function、programごとのaggregate codec、target sizeに固定幅整数を流用するcontractを並立させると、利用者は
同じlayout、offset、admissionを型ごとに再判断する必要がある。productとsumの構造からlayoutを一意に導き、Cursorが選択済みlayoutを
運べば、modelを理解した後のoperationは一つの規則から予測できる。

同時に、canonical source memory layoutをruntime representation、public C aggregate carrier、wire formatへ流用するとauthorityが
混ざる。この決定は固定mechanismだけをlanguage primitiveに置き、resource policyとprotocol encodingをexternまたはmal codecへ残す。
これはsurface feature数や変更量ではなく、system全体の独立contractとcall siteごとの再判断を減らすminimalityである。

generic layout dictionaryやruntime type descriptorを使わずspecialization前に型形成条件を検査することで、ANF以降は従来どおり
concrete typeだけを扱える。operation探索を導入しないため、generic codeのcontrolとcostもsourceから追跡できる。

## 置き換える判断

[D022](D022.md)、[D024](D024.md)、[D027](D027.md)、[D037](D037.md)の`Ptr`、型修飾memory primitive、storage-size queryの
source modelを置き換える。[D030](D030.md)のprocess argument carrierを`(USize, Address)`とcanonical descriptor shapeへ置き換える。
[D013](D013.md)のnumeric conversion semanticsは維持し、source spellingだけをpostfix suffixへ置き換える。
[D031](D031.md)のEngram/Extern authorityと[D035](D035.md)のprecondition方針は維持し、aggregate canonical layout、Region、Packedへ
適用範囲を広げる。

generic specializationとcanonical layoutの現在の規範は[型](../../spec/types.md)、[generics](../../spec/generics.md)、
[external memory](../../spec/memory.md)、[grammar](../../spec/grammar.md)、[C host ABI](../../spec/c-host-abi.md)を正とする。
Cursor、Region、Packedを使うsurface modelは履歴であり、現在のmemory operationには適用しない。
