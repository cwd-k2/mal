# 履歴文書index

Status: Historical records

このdirectoryは、現在のruleそのものではなく、採択済み判断の理由、退役した判断、測定結果を保存する唯一の場所である。
現在の言語ruleは[`spec/`](../spec/)、compilerの現在の責務と構成は[`implementation/`](../implementation/)、
現在の開発手順と作業計画は[`development/`](../development/)を正とする。

| 場所 | 保存する履歴 |
|---|---|
| [`decisions/`](decisions/) | 設計判断、代替案、後継関係 |
| [`performance/`](performance/) | 日付と測定条件を伴う性能記録 |

現在の文書とsource commentには移行経緯、以前の名称、完了済み作業、棄却済み実験を残さない。
現在のruleを理解するために理由が必要な場合は、このdirectoryの該当recordへlinkする。
