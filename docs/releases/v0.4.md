# mal v0.4 release profile

Status: Release candidate 1

v0.4はRust製reference compilerとC backendを持つ最初の実装済みlanguage profileである。
規範的な言語規則は[`spec/`](../spec/)、releaseまでの残作業は[roadmap](../implementation/roadmap.md)を正とする。

このcandidateはlanguage profile v0.4、`malc` package `0.4.0-rc.1`、C host ABI
`MAL_C_ABI_VERSION == 0x000400u`の組合せである。対応環境と生成物の扱いは
[reference compiler利用contract](../development/compiler-usage.md)に定める。

## 提供する範囲

- strict call-by-value、immutable binding、lexical closure、annotated self recursion
- product、n-ary sum、predefined `Bool`
- 全固定幅integer、`i8`〜`u64` suffix、byte literal
- strict `Float32` / `Float64`と`f32` / `f64` suffix
- mal-ownedなprogram-lifetime immutable `String`
- external opaque handleとgenerated C host ABI
- `check`、`emit-c`、`build`のpublic CLI

I/O、mutable storage、resource lifecycleなどの作用はhost adapterへ置く。functionを含むextern signature、module、
package manager、GC、ownership type、thread、exceptionはv0.4に含めない。完全な境界は[scope](../spec/scope.md)に定める。

## release gate

M0〜M5の実装、conformance matrix、公開toolchain contract、package versionはcandidateとして揃っている。
clean checkoutのpinned environmentでformat、Clippy、全test、M0〜M5のchecked-in example、release buildを
再検証済みである。
