# mal v0.4 implementation draft

Date: 2026-09-04

v0.4は、従来草案を議論結果に合わせて再基線化し、reference compiler実装へ移る版である。`docs/spec/`を規範文書とする。

## fixed direction

- reference compilerはRust、最初のbackendはC
- strict call-by-valueと左から右の評価
- immutable bindingと明示capture listを持つlexical closure
- closure environmentはprogram-lifetime storage
- n-ary sumは`[A, B, C]`
- `Bool :: [Unit, Unit]`、surface `if`は`case`へdesugar
- byte literalは`b'…' :: UInt8`
- Float32/64は固定roundingのIEEE 754-2019 profile
- Stringはmal-ownedなprogram-lifetime immutable bytes
- mutable bufferはexternal opaque typeへ分離
- numeric separatorをdigit間に許可
- extern implementationはgenerated headerに対するC adapterをlink
- functionを含むextern signatureは暫定的に禁止

## implementation entry

最初のvertical slice、作業順、CLI target、受入条件は[M0 implementation plan](../implementation/m0.md)に定める。hostとの初期interfaceは[C host ABI](../spec/c-host-abi.md)に定める。

Rust workspaceは`compiler/`に置く。bootstrap時点では`--help`と`--version`だけを実装し、未実装のcompile commandを成功扱いにしない。

## intentionally open after baseline

- opaque resource safety
- C aggregate ABIの実装結果に基づく改善
- top-level initializationの最終形
- trapのembedding mapping
- integer型間conversion
- shift count型
- `String`という名称
- `return`、comment、trailing commaなどの最終lexical polish

これらはM0に必要な暫定profileがある項目と、M0の機能範囲外の項目に分離されている。実装中に仕様差が見つかった場合は、暗黙にcompiler behaviorへせず、`docs/design/decisions.md`へdecisionを追加してから規範文書を更新する。
