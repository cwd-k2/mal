# M0 implementation record

Status: Archived; completed

M0は、一つのmal sourceを検査し、Cへ変換し、host C adapterとlinkして実行する最初のvertical sliceだった。
現在の言語範囲やcompiler contractを定める文書ではない。現行仕様は[`spec/`](../spec/)、残作業は
[roadmap](roadmap.md)を参照する。

## 完了したslice

- `Unit`、`Int32`、predefined `Bool`
- n-ary sum、injection、exhaustive `case`、surface `if`
- immutable binding、typed lambda/application、明示capture list
- block result expression、`Int32` / `Unit` extern、`main :: Unit -> Int32`
- source span付きdiagnosticと`check`、`emit-c`、`build`
- C translation unit、generated header、host adapterのcompile/link/execute

M0後に固定幅integer、product、opaque handle、`String`、self recursion、tail-call lowering、strict Floatを追加した。
したがってM0の対象外だった機能を現在の未実装項目として扱わない。

## 保持する基線

- strict call-by-valueと左から右の一回評価
- lexical closureと明示capture、scope外へescapeするenvironment
- signed arithmeticのwrapとdivision trapをC undefined behaviorへ依存させない
- functionを含むextern signatureのrejection
- warningをerrorにするC compileを含むnative test
- stageごとのpositive/negative testとpublic CLIのend-to-end test

checked-in programと実行手順は[`examples/m0/`](../../examples/m0/print-and-closure/README.md)、現在の検証commandは
[test policy](../development/testing.md)、正確なhost interfaceは[C host ABI](../spec/c-host-abi.md)を参照する。
